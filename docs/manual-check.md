# 旅ガチャ 目視確認チェックリスト

Task 1〜18 を通して台帳に溜まった「未実施: ブラウザでの目視確認」を1枚にまとめたもの。
実装側のロジックはテスト182件で固定済みなので、ここに残るのは**人の目でしか確かめられないもの**だけ。

## 準備

```bash
npm run dev          # http://localhost:5173
```

幅の切り替えは開発者ツールのデバイスツールバー（Ctrl+Shift+M）で **375px / 768px / 1280px** の3つ。
仕様9.1がこの3点を確認幅として定めている。

**HTTPSが必要で、ローカルでは確認できない項目**には 🔒 を付けた。これは Vercel デプロイ後に
スマホで確認する（Task 19 Step 4）。

---

## A. 全幅で共通（3つの幅それぞれで見る）

- [ ] 横スクロールが出ない（375pxで特に。カードの見出しや注釈が溢れていないか）
- [ ] タップ対象が押しやすい（44px以上。ミッションのチェック、並べ替えボタン、デモモードのボタン、写真の削除）
- [ ] 本文の行長が長すぎない（注釈・行き方のコツが画面幅いっぱいに伸び切らない）
- [ ] ナビゲーションの位置が切り替わる：375pxでは下部固定、768px以上では上部の横並び
- [ ] 配色と書体が意図どおり（藍の地に紅白、見出しは標識風のプレート。「生成されたUI」に見えないか）

## B. ホーム（タブ「ひく」）

- [ ] ガチャ機が描かれていて、ハンドルを回す/引くボタンが機体の一部として見える
- [ ] 引くとカプセルが取出口から落ち、割れて町が出てくる一連の流れが動く（別画面に飛ばない）
- [ ] 出てきた町の名前が標識として読める。郡つきの町（例「紋別郡西興部村」）で郡が小さく市町村名が大きい
- [ ] レア度のバッジが出る
- [ ] 注釈「有名な街は入っていません ― 出るのは人口10万人未満の市町村だけ」が常に見えていて、タップで展開する
- [ ] 展開した中にレア度表（SSR 3,000人未満 など4行）と排出率が並ぶ
- [ ] モード選択が動く：全国＋8地方（北海道/東北/関東/中部/近畿/中国/四国/九州沖縄）
- [ ] 1回引いたあとボタンが無効になり、「明日また引ける」ことが分かる文面が出る
- [ ] OSの「視差効果を減らす」を有効にすると演出が控えめになる（prefers-reduced-motion）

## C. カード詳細

- [ ] ミッションが3枚。1枚目が固有（その町のこと）、2〜3枚目が汎用
- [ ] チェックを入れるとポイントが増え、外すと減る
- [ ] 戻るとプロフィールの累計ポイント・称号が更新されている
- [ ] 段組みが幅で変わる（375pxで1列、1280pxで横に並ぶ）
- [ ] AI生成であることの注釈が読める位置にある

## D. 行き方

- [ ] 「Googleマップで経路をひらく」が**文字のみ**（Googleのロゴが入っていない。仕様11.5.1）
- [ ] **位置情報の許可ダイアログが出ない**（仕様6.3でアプリは位置情報を取得しない）
- [ ] 🔒 スマホで押すとGoogleマップのアプリが開き、**現在地からその町への経路**が出る（出発地はGoogleマップが決める）
- [ ] Googleマップ側で出発地を「東京駅」などに変えられる
- [ ] プロフィールの位置情報の注釈が仕様6.4どおり（「端末の外に一切出ない」と書かれていないこと）

## E. コレクション（タブ「あつめた」）

- [ ] 列数が幅で変わる（375pxで2列、1280pxで4〜5列）
- [ ] 並べ替えが動く（押したボタンが選択状態に見えるか）
- [ ] 同じ町を2回引いたら2枚並ぶ（別の旅として扱う設計）
- [ ] 1枚も無い状態の表示が寂しすぎない

## F. プロフィール（タブ「じぶん」）

- [ ] 称号と累計ポイントが出る
- [ ] 出典表記が読める：e-Stat（政府統計の総合窓口）と、**ミッション・行き方のコツがAI生成である**明示
- [ ] 写真の保存についての注釈が常設されている（仕様8.1）
- [ ] デモモードのパネルがある

## G. 写真

- [ ] 「＋追加」の初回に警告（この端末にしか残らない）が出る
- [ ] 🔒 スマホで**カメラとギャラリーの選択が出る**（カメラが直接起動しない。仕様8）
- [ ] 🔒 スマホでギャラリーから**既存の写真**を選んで貼れる
- [ ] PCではファイル選択になる
- [ ] 追加した写真がカードに出る。**連続して追加/削除しても隣の写真が一瞬映るズレがない**（今回の minor #1）
- [ ] 削除が2段確認（1回のタップでは消えない）
- [ ] リロードしてもカードと写真が残っている
- [ ] 保存できない環境（プライベートウィンドウ）で開くと、保存できないことがホーム画面のバナーで伝わる

## H. デモモード（発表用）

- [ ] 有効にするとレア度を固定できる。`SSR` にしてホームで引くとSSRの町が出る
- [ ] 回数制限が解除され、連続で引ける
- [ ] デモモードが有効であることが画面上で分かる（本番の挙動と混ざらない）

## I. 発表の通し（Task 19 Step 5）

1. [ ] プロフィールでデモモードON → レア度 `SSR` 固定
2. [ ] ホームで引く → SSRの町が出る（演出を見せる）
3. [ ] カード詳細で 注釈 → ミッション → 行き方 → 写真 をひと通り見せる
4. [ ] 制限解除のまま数回引き、コレクションが埋まった状態を作る
5. [ ] プロフィールで称号が上がっているところを見せる

## J. 🔒 デプロイ後にスマホで（Task 19 Step 4）

- [ ] 公開URLをスマホで開ける
- [ ] Googleマップの経路が現在地から出る（許可ダイアログは出ない）
- [ ] ギャラリーから既存の写真 → 残る → リロードしても残る
- [ ] カメラで撮影 → 残る
- [ ] 横スクロールなし・タップしやすい
- [ ] 同じURLをPCでも開き、タブが上部・コレクションが4〜5列

そのまま修正に入れます。例：「375pxのカード詳細で、行き方のコツが右に溢れて横スクロールが出た」
